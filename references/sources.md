# 来源与借鉴边界

读取日期：2026-10-27。设计资料：
- [Adobe 海报设计](https://www.adobe.com/express/learn/blog/poster-layout-design)：单一主信息、观看距离与阅读层级。
- [Adobe 基础设计原则](https://blog.adobe.com/en/publish/2016/08/11/8-basic-design-principles-to-help-you-create-better-graphics)：邻近关系与分组。
- [W3C 中文排版需求草案](https://w3c.github.io/clreq/)：混排文字的比例与间隔参考，草案并非通用海报字距标准。
- [Monotype 光学尺寸](https://www.monotype.com/resources/articles/what-is-optical-sizing-and-how-can-it-help-your-brand)：展示与阅读字号的不同需求。

参考技能，按方法吸收而非复制代码：
- [k2f-event-poster](https://github.com/suzheng/k2f/tree/main/skills/marketing/k2f-event-poster)：活动身份、参会信息、单一CTA的层级；未采用其专用引擎和固定上中下版式。仓库 Apache-2.0 许可已核对，未复制内容。
- [frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)：从品牌主题决定形式、克制地使用一个记忆点；未把网页交互规则当海报规则。
- [imagegen](https://github.com/openai/skills/tree/main/skills/.system/imagegen)：区分生成/编辑、守住身份不变量、保存项目素材；按宿主当前工具能力执行。
- [latex-posters](https://github.com/k-dense-ai/scientific-agent-skills/tree/main/skills/latex-posters)：文字/二维码可编辑与实际渲染检验；不采用学术多栏密文和LaTeX依赖。

代码是此技能独立实现；本地qiaomu-design和本批次反复修订提供实践案例。catalog安装量与仓库stars仅是采用度/仓库关注度，不是评分。没有公平对照实验，不主张比所有其他技能更好。
