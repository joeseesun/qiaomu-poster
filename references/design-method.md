# 商业海报设计方法

## 信息先于样式

用一份事实清单驱动所有海报：每条记录原文、来源URL、读取日期、用户覆盖项、是否必需。会议名称是不可随意拆分的身份单元；日期、酒店、票价属于事实层；营销句允许编辑，但不能添加不存在的保证或稀缺性。网页内容过期/不完整时不能猜。联名媒体仅标“邀你参加/媒体伙伴”，没有依据不能升级为主办方。

把内容压成三个阅读距离：第一眼看见活动名称与参加理由；稍停留读到时间、地点、价格；靠近或保存后扫码。标题、主体、信息区不必固定上中下，阅读顺序才是约束。

## 先写构图，再挑颜色

每个品牌记录：辨识物、个性、材质、隐喻、主体位置、标题位置、信息分区、字形角色、主次关系。隐喻应是具体物体/动作，如烟花绽放、人物穿过轨道、书页翻开；“科技/高级/卡片”不是隐喻。

比较至少三个真实内容样稿：强字体构图、主体叙事、图形/品牌空间。选择依据是受众和品牌，不强制某一风格。批量样稿用同尺度并排看：如果抹去颜色后结构相同，不算独立设计。系列可以共享信息规范，不要求每张所有细节都不同。

## 中西文与字体

- 一个名称形成一个完整组。用 inline-flex + baseline 只是起点；中文方块、Latin cap height、字重、衬线对比需要实际字面校准。
- 在1080px画布，本案例以12–24px组间空隙起步，最终大多18px；按比例与字形调整，不能把这个数值当国际标准。
- 大标题使用适合展示的字形，信息字选择清楚的阅读字体；通常1–2类字体角色足够。高对比衬线GEO配宋体，厚黑体配相近重量的黑体，不机械混搭。
- 中文不通过横向拉伸、斜体、极端负字距挤入；先缩短文案、换行或调整字号。英文大写逐对看字距，不用平均分布撑满画布。
- 自定义字体族使用唯一别名（如 `PosterSerif`），不要用 `Serif` 这类 CSS 保留通用族名称，否则声明可能被忽略而静默回退。实际渲染确认中文宋体字面，不能只看 CSS 中写了字体名。
- variable font 声明正确权重范围。打包本地可再分发字体及许可；系统字体造成跨机差异时，以交付PNG为确定版面并说明限制。
- 日期/票价用清楚数字；单位从属但不消失。地点长名称用主店名+分店名两行、细地图pin，避免硬挤一行。

## 图文关系

文字必须落在足够平静的区域。主体可以越过色面、被前景挡住或与字形前后交叠，但不能遮挡活动名称、事实或CTA。一个可记忆的视觉动作足够；无意义线条、发光和装饰会稀释主次。

先看全幅，再看手机缩图，再看标题、头像边缘与二维码局部。自动检测不能发现所有光学间距、假透明、遮挡与气质问题；必须打开实际成图。失败后修改根因再渲染，不能用抽象好评代替检查。
